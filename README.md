# tapgraph

Tap CSV/TSV graph tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/tapgraph/

## Install / run

```bash
git clone https://github.com/theworker02/tapgraph.git
cd tapgraph
node src/cli.js
node --test
```
